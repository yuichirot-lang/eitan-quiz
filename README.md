# eitan-quiz

中学校英語（Here We Go! 1）の授業で使う Web 教材集です。GitHub Pages でそのまま公開できます。

| ページ | ファイル | 内容 |
| --- | --- | --- |
| 英単語テスト | `index.html` | 単元ごとの英単語テスト。結果をスプレッドシートに送信 |
| Life in Hawaii ブログ | `blog.html` | 教科書のブログ記事を読み、英語でコメントを書き合う |

---

## blog.html ―― ブログにコメントしよう（Cafe Maria）

### 授業の流れ（10分程度のコメント活動）

生徒への指示はすべて英語で表示されます（語句の意味と日本語訳だけ日本語です）。

| | 生徒の活動 | ページの機能 |
| --- | --- | --- |
| ① 読む | ブログ記事を読む | 🔊 Listen（全文・1文タップで読み上げ）、🐢 Slow、📖 Word meanings、🇯🇵 日本語訳 |
| ② 書く | Kaito の質問 *Do you want to visit this restaurant?* にすぐコメントを書く | Class / Number / Name ＋ コメント欄、Useful expressions（タップで入力）、語数カウント |
| ③ 読み合う | クラス全員のコメントを読む | 件数表示、フィルタ（All / Mine）、並び替え（Newest / Most liked）、👍 Like |

- Yes / No を選ぶステップはありません。生徒は読んだらそのまま英語で書きます。
- 生徒はログイン不要。URL（または QR コード）を開くだけで使えます。
- クラス・出席番号・名前は端末に記憶されるので、2 回目からは入力不要です。
- 20 秒ごとに自動更新されるので、友だちのコメントが次々に表示されます。

### 先生用の機能

URL の最後に `?teacher=1` を付けて開くと、先生用パネルが表示されます。

```
https://<ユーザー名>.github.io/eitan-quiz/blog.html?teacher=1
```

- **🖥 提示モード切替** … 入力欄を隠し、文字を大きくします（電子黒板・プロジェクタ用）
- **⏱ 10分タイマー** … 活動時間のカウントダウン（長さは `CONFIG.MINUTES` で変更）
- **📋 コメントをコピー（CSV）** … 全コメントをコピー。スプレッドシートにそのまま貼り付けられます
- **削除** … 各コメントの「削除」（パスコードが必要）

### クラスごとにコメントを分ける

URL に `?room=` を付けると、クラスごとに別々のコメント欄になります。

```
https://<ユーザー名>.github.io/eitan-quiz/blog.html?room=1-1      ← 1年1組
https://<ユーザー名>.github.io/eitan-quiz/blog.html?room=1-2      ← 1年2組
https://<ユーザー名>.github.io/eitan-quiz/blog.html?room=1-1&teacher=1
```

## コメントを共有する設定（Google Apps Script）

設定しなくてもページは動きますが、その場合コメントは **その端末だけに保存**されます
（画面下に「おためしモード」と表示されます）。クラス全員でコメントを読み合うには、
次の手順で 5 分ほどの設定をしてください。

1. **スプレッドシートを新規作成**します（名前は「英語コメント」など何でも構いません）。
2. メニューの **拡張機能 → Apps Script** を開きます。
3. 表示されたコードをすべて消し、この repository の **`apps-script/comments.gs`** の中身を貼り付けます。
4. 先頭の `TEACHER_PASSCODE`（削除用パスコード）を、自分の決めた文字列に変更して保存します。
5. 右上の **デプロイ → 新しいデプロイ** を選び、
   - 種類：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   を選んで「デプロイ」。表示された **ウェブアプリの URL** をコピーします。
   （初回は「承認」を求められます。「詳細」→「（プロジェクト名）に移動」で許可してください）
6. `blog.html` を開き、上のほうにある設定を書きかえて保存・push します。

```js
const CONFIG = {
  GAS_URL: 'https://script.google.com/macros/s/××××××/exec',   // ← 5でコピーしたURL
  ...
};
```

7. ページを開き直し、画面下が「**共有モード：みんなのコメントが表示されます**」になれば完了です。

> コメントはスプレッドシートの `comments` シートに 1 行ずつ記録されます。
> 授業後にそのまま評価・振り返りの資料として使えます。
> 削除したコメントは行が消えるのではなく `deleted` 列に `1` が入り、ページに表示されなくなります。

## 他の題材に作りかえるには

`blog.html` の `<script>` の先頭にある `CONFIG` を書きかえるだけで、質問や表現例を変えられます。

```js
const CONFIG = {
  BLOGGER: 'Kaito',                                        // 登場人物の名前
  QUESTION_EN: 'Do you want to visit this restaurant?',    // 生徒への質問
  QUESTION_HINT: 'Write your answer in English. ...',      // 書き方の指示（英語）
  MINUTES: 10,                                             // 活動時間（タイマー）
  CHIPS: ['Yes, I do.', 'It looks delicious.'],            // 使える表現（タップで入力）
  ...
};
```

本文そのものを差しかえるときは、`<div class="article">` の中の `<span class="sent">`（1 文）と
`<span class="gl" data-ja="意味">`（語句の意味）を書きかえてください。
